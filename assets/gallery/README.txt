Drop your product photos in this folder, then edit index.html
to point each gallery item at your image. See the comment block
just above the "GALLERY / PRODUCTS" section in index.html for
step-by-step instructions.

Tips:
- Portrait photos (roughly 4:5, e.g. 1000x1250px) look best.
- Keep file sizes reasonable (under ~500KB each) so the site
  loads quickly. Most phone photo editors can "compress" or
  "export for web" to reduce file size.
- Use clear, lowercase filenames with no spaces, e.g.
  red-kurta-set.jpg, festive-lehenga.jpg
